# 🔌 ÜrünBul Chrome Extension (Uzantı)

Trendyol satıcıları için **Helium 10 Xray** benzeri tarayıcı eklentisi.

## 🚀 Chrome'a Nasıl Yüklenir?

1. Google Chrome tarayıcınızı açın ve adres çubuğuna `chrome://extensions` yazın.
2. Sağ üst köşedeki **Geliştirici modu (Developer mode)** anahtarını açın.
3. Sol üstteki **Paketlenmemiş öğe yükle (Load unpacked)** butonuna tıklayın.
4. Bu klasörü seçin:
   `c:\Users\UlubeyKütüphane1\Desktop\AI\urunbul\apps\extension`
5. Artık uzantı kuruldu! Trendyol'da gezinirken uzantı simgesine tıklayarak anlık satış ve fırsat analizini görebilirsiniz.
